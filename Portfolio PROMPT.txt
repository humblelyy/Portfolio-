VISUAL DIRECTION - Cinematic dark navy/near-black background with subtle
grain and atmospheric blue/red glows. - Strong red accent (around
#ff3b2f), warm cream text, and muted lavender/grey supporting text. -
Large condensed display typography similar to Bebas Neue; DM Sans for
readable body text; JetBrains Mono for technical labels and timecodes;
Permanent Marker for handwritten annotations. - Use a film-camera /
director’s-cut visual language: viewfinder corners, REC indicator,
camera timecode, timeline ruler, clip labels, play icons, waveform
motifs, frame counters, and editorial notes. - Keep the interface
expressive and handmade-looking, not overly polished into a generic SaaS
template. - Use the existing original portfolio assets where provided.

width/height appropriately, height:auto for natural images, and
object-fit:contain when the full subject must remain visible. Use
object-fit:cover only for intentional crops. - Support desktop, tablet,
and mobile. On mobile, maintain legible typography, touch-friendly
controls, no horizontal overflow, and lightweight animation.

LOADING AND PERFORMANCE - Keep the loading screen simple and brief: the
MAHESH. wordmark, a slim progress line, and a quick fade. Avoid
elaborate countdowns, giant circular loaders, or long blocking intros. -
Provide skeleton loading placeholders for media/content that is still
loading. Skeletons must disappear when the actual content loads or show
a clear unavailable state if it fails. - Optimize images using WebP/AVIF
where suitable, but keep source originals when needed. Declare
dimensions to reduce layout shift. - Lazy-load below-the-fold images and
video previews. Load heavy video only when needed. - Reduce unnecessary
continuous JavaScript loops, expensive blur, parallax, and animation
complexity on mobile. - Use CSS transforms/opacity for motion where
practical. - Honor prefers-reduced-motion. - Ensure the ticker remains
moving on touch devices and all essential content stays visible if
animation is reduced or disabled.
