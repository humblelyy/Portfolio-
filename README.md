# Mahesh Creative Portfolio

Production-ready static portfolio for Mahesh M — Creative Designer / Video Editor / Computer Engineer.

## Local preview
Use any static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Vercel
Import this folder/repository into Vercel as a static site.
- Framework preset: Other
- Build command: none
- Output directory: `.`

All portfolio videos, thumbnails, character PNGs, CSS, JS, and Vercel configuration are included.
